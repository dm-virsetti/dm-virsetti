## 📊 Featured Projects

### [Superstore Sales & Profitability Analysis](https://github.com/dm-virsetti/superstore-sales-profitability-analysis)
Interactive Power BI dashboard exploring retail sales, profitability, product categories, regions, and discount levels. Includes the `.pbix` file, dashboard preview, and source dataset.

**Tools:** Power BI, DAX, Power Query

### [Macroeconomic Database for Poland](https://github.com/dm-virsetti/macroeconomic-database-sql)
Relational MySQL database built for a bachelor's thesis project. Organises six macroeconomic indicators across quarterly periods and demonstrates relational design, data import, joins, aggregations, and window functions.

**Tools:** MySQL, SQL, MySQL Workbench

### [Czech HICP Inflation Forecasting](https://github.com/dm-virsetti/czech-hicp-inflation-forecasting)
Time-series econometrics project analysing monthly HICP inflation in Czechia. The report covers stationarity testing, a dynamic ADL specification, diagnostic checks, and forecast evaluation.

**Methods:** Econometrics, time-series analysis, ADF testing, ADL modelling

### [Amateur Tennis Research in Warsaw](https://github.com/dm-virsetti/amateur-tennis-research-warsaw)
Collaborative research-design project exploring potential barriers to continued amateur tennis participation in Warsaw. Covers research questions, hypotheses, CAWI questionnaire design, expert interviews, sampling considerations, and a proposed analysis plan.

**Methods:** Research design, survey methodology, descriptive statistics planning
